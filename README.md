# SafarNest

A mobile-friendly Pakistan tourism website for showcasing destination ideas and collecting trip inquiries through WhatsApp.

## Preview

Open `index.html` in a browser. No installation or build step is needed. External destination photos and Google Fonts require internet connectivity.

## Booking / enquiries

WhatsApp: **+92 317 5495052** (`https://wa.me/923175495052`). Tour and inquiry buttons direct visitors to WhatsApp; the trip form prepares a prefilled enquiry, not an instant reservation or payment.

## Before public launch

Destination and journey examples are illustrative, not confirmed tour inventory. Confirm packages, availability, pricing, policies, and licensed images before advertising real bookings.

This repository contains a self-contained `index.html` with inline CSS and JavaScript. Updates to `main` may trigger automatic deployment if Git-based deploys are enabled in Netlify.
